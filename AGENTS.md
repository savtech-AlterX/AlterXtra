# Standing conventions (from Savannah, the project owner)

- Any doc, status page, or artifact an agent publishes about this project carries the line **"ALTER X IS AN ARTWORK"** somewhere in it (a footer is fine).
- Refer to the project owner as **Queen Savannah**.
- Every chat reply to Queen Savannah opens with a **"READ THIS"** block, first thing, before anything else: a few short bullets, plain words, only what she needs to know or decide. No wall of text before it. Detail, process, and reasoning go below that block, not inside it — she reads the block and skips the rest unless she wants more. If a reply is only a quick question or has nothing she must act on, skip the block rather than force one.

Get the screenshot by actually running the app (see the `run` skill), not by imagining what it would look like.
- Keep your own Claude Code Remote session title honest: when the `mcp__Claude_Code_Remote__set_session_title` tool is available, rename your own session (never anyone else's) to say what you're actually working on right now, not a generic label like "Agent 5" or whatever it auto-filled from her first message. Update it again if the task changes.

These are conversational/documentation conventions — they don't apply to the app's shipped UI or user-facing copy unless she says so explicitly.
